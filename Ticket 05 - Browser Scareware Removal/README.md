Tech Support Scam (Scareware) Incident Report
Reported by: David Lee
Department: Support
Location: Floor 3
Incident Summary
The user experienced a full-screen fake virus warning with an alarm, countdown timer, and a
fraudulent support phone number. The user did not call the number and contacted the IT Service
Desk instead.
Business Impact
The user was unable to continue working while the scareware page occupied the screen, creating a
risk of social engineering.
Investigation
Confirmed the user had not contacted the fake support number. Connected through Remote
Support and identified the issue as a browser-based scareware page rather than confirmed
malware.
Resolution
1. Reassured the user not to call the displayed number.
2. Connected remotely to the computer.
3. Moved the mouse to the upper-left corner to reveal the browser close control.
4. Closed the fake warning page.
5. Ran a Microsoft Defender Full Scan.
6. Confirmed no threats were detected.
7. Verified the desktop returned to normal.
8. Educated the user on recognizing future tech support scams.
Outcome
The scareware page was successfully removed, the security scan found no malware, and the user
safely resumed work.
Skills Demonstrated
Remote Support, Microsoft Defender, Security Incident Response, Scareware Identification, User
Education, Social Engineering Awareness, Professional Troubleshooting
