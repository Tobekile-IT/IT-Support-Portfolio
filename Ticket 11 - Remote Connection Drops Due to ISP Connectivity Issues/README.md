Help Desk Technician – Lab 09
Remote Connection Drops Due to ISP Connectivity Issues
Issue Description
The user experienced intermittent Remote Desktop, VPN, video conferencing, and web browsing
disconnects while working from home. The issue began the same morning.
Business Impact
The unstable connection prevented reliable access to the financial reporting system and disrupted
normal work.
Investigation
Verified only the work laptop was affected. Confirmed Wi-Fi signal strength was good and Internet
connectivity tests responded successfully. Considered Wi-Fi, VPN, laptop configuration, and ISP
connectivity before identifying the ISP as the remaining likely cause.
Resolution
Advised the user to contact their Internet Service Provider (ISP) to check for maintenance or
service interruptions. After contacting the ISP, the connectivity issue was confirmed and resolved,
restoring stable access.
Skills Demonstrated
Remote Support, Network Troubleshooting, Logical Troubleshooting, Root Cause Analysis,
Connectivity Diagnostics, End-User Support, ISP Escalation.
Outcome
The user's VPN, Remote Desktop, video calls, and web browsing returned to normal after ISP
intervention
