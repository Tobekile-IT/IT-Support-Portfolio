Maria Johansson is starting in Finance. Her Active Directory account already exists, but the onboarding setup is
incomplete. The technician must enable the account, place it in the Finance OU, assign Finance-GG, and assign a
Microsoft 365 E3 license.
2. Objective
Complete the employee's identity and access setup so the account is enabled and aligned with the Finance
department's OU, group membership, and Microsoft 365 licensing.
3. Administration Process
1. Located Maria Johansson's existing Active Directory account.
2. Checked the account state and ensured that the account was enabled.
3. Moved the account into the Finance organizational unit.
4. Assigned the Finance-GG group.
5. Assigned the Microsoft 365 E3 license.
6. Verified the account was enabled, in the Finance OU, a member of Finance-GG, and assigned the required
M365 license.
7. Used the Service Desk simulator verification to confirm the solution.
8. Closed the ticket after successful verification.
4. Verification
The simulator confirmed the required final state: Maria's account enabled, OU set to Finance, Finance-GG
assigned, and the M365 license set. The ticket was successfully resolved.
5. Skills Demonstrated
Active Directory account management; OU management; group-based access management; Microsoft 365
licensing; employee onboarding; identity and access administration; configuration verification; service desk ticket
handling.
6. Key Learning
A complete employee onboarding request can involve several connected administration tasks. The account,
organizational unit, group membership, and cloud license all need to match the employee's department and role.
7. Portfolio Summary
This lab demonstrates progression beyond basic account troubleshooting into practical Windows administration,
identity management, group-based access, and Microsoft 365 administration
