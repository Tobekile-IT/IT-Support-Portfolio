1. Scenario
Windows / Active Directory
New employee onboarding / user provisioning
A new employee, Erik Johansson, is starting in the Sales department. The service desk request required a new
Active Directory account to be created in the Sales OU and assigned to the Sales-GG and All Employees groups.
2. Objective
Provision the employee's Active Directory account correctly and ensure the account has the required
organizational placement and group memberships.
3. Procedure
1. Opened the Active Directory / directory management tool.
2. Navigated to the Sales organizational unit.
3. Created a new user account for Erik Johansson using the username erik.
4. Configured the account according to the standard onboarding procedure.
5. Assigned the user to the Sales-GG group.
6. Assigned the user to the All Employees group.
7. Checked that the account was located in the correct Sales OU.
8. Verified the account configuration using the Service Desk simulator.
9. Closed the ticket after successful verification.
4. Verification
The simulator verification confirmed that the erik account existed with the correct group memberships. The ticket
was then closed.
5. Skills Demonstrated
Active Directory user provisioning; user account creation; organizational units (OUs); group membership;
onboarding procedures; access management; configuration verification; service desk ticket handling and
documentation.
6. Key Learning
User onboarding is more than simply creating an account. The technician must ensure the account is placed in the
correct OU and receives the appropriate group memberships, because group membership can determine the
resources and permissions available to the employee.
