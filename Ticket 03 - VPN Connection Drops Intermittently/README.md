Ticket 03 – VPN Connection Drops Intermittently
Priority: Medium
User: Lisa Martinez (Remote Worker)
Issue: VPN disconnected every 15–20 minutes while working from home while normal internet
browsing continued to work.
Business Impact: Productivity was impacted because the user could not maintain a stable
connection to internal company systems.
Troubleshooting Process
1. Reviewed the incident details.
2. Confirmed the user was using a personal laptop.
3. Verified the user had already restarted the home modem/router.
4. Guided the user to restart the PC and reconnect the VPN.
5. Confirmed the VPN connection remained stable.
6. Verified access to company resources was restored.
Root Cause
A temporary VPN session or home network state caused intermittent disconnects. Re-establishing
the VPN session after restarting the workstation resolved the issue.
Resolution
Restarted the PC, reconnected the VPN, confirmed the connection remained stable, and closed the
ticket.
Skills Demonstrated
Remote support, VPN troubleshooting, logical troubleshooting, customer communication, root
cause analysis, and documentation
